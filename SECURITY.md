# Política de seguridad

## Reportar una vulnerabilidad

No abra un issue público. Use **Security → Report a vulnerability** en este repositorio (reporte privado de GitHub). Indique la versión, los pasos para reproducirla y el impacto.

Se responderá el reporte y, si se confirma, se corregirá en `devmarlon`, se verificará en `pruebas` y se publicará en `main`.

## Alcance

- API (FastAPI), aplicación web (React) y scripts de arranque.
- Configuración de contenedores (`docker-compose.yml`, `Dockerfile`).

Los datos de UNEMI_PRUEBAS son sintéticos y anonimizados; el repositorio no contiene datos personales reales ni credenciales.
